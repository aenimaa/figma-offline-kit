فیگما قطع شد؟
کارتان متوقف نمی‌شودFigma’s down?
Your work isn’t.

چه چیزی تحویل می‌گیریدWhat you get

همه‌چیز روی دیسک خودتان، در پوشه‌هایی به ترتیب پروژه، فایل، صفحه و سکشن.

Everything on your own disk, in folders by project, file, page and section.

🗺️

گالری آفلاین برای هر فایلAn offline gallery for every file

همهٔ فریم‌ها به‌صورت PNG و SVG. مثل بوم فیگما در آن‌ها بگردید: نقشه‌ای از جای هر فریم، درخت صفحه‌ها، فیلتر، جست‌وجو و نمایشگر تمام‌صفحه. از روی دیسک باز می‌شود و اینترنت لازم ندارد. با تم روشن و تیره.

Every frame as PNG and SVG. Browse them like the canvas: a map of where each frame sits, a page tree, filters, search and a full-screen viewer. It opens from disk, no internet needed, in light or dark.

🎨

توکن‌های طراحی کنار هر صفحهDesign tokens next to every screen

متغیرهای شما به‌صورت tokens.css و _tokens.scss. برای هر صفحه، توکن‌ها و استایل‌هایی که استفاده کرده و رنگ‌هایی که به هیچ توکنی وصل نیستند.

Your variables as tokens.css and _tokens.scss. For each screen, the tokens and styles it uses, and the colours bound to nothing.

بستهٔ تحویل به برنامه‌نویسA handoff package for developers

برای صفحه‌هایی که برنامه‌نویس لازم دارد: برای هر فریم یک صفحه با طراحی، کد، توکن‌ها و آناتومی، خروجی design-to-code خود فیگما و مشخصات کامپوننت‌ها.

For the pages a developer needs: one page per frame with design, code, tokens and anatomy, Figma’s own design-to-code output, and component specs.

گزارشی از آنچه داریدProof of what you have

صفحهٔ COVERAGE.html همهٔ پروژه‌ها، فایل‌ها و صفحه‌ها را نشان می‌دهد: چه چیزی پشتیبان شده، چه چیزی و چرا کنار مانده، و کدام فایل‌ها از آن به بعد در فیگما عوض شده‌اند. هر پروژه هم در یک آرشیو آزموده بسته می‌شود.

COVERAGE.html shows every project, file and page: what’s backed up, what’s left out and why, and which files changed in Figma since. Each project is packed into a tested archive.

💾 و خود فایل‌هاAnd the real files

نسخه‌های محلی fig، jam و deck از فیگمای دسکتاپ. هوش مصنوعیِ دارای کنترل دسکتاپ ذخیره‌شان می‌کند، یا خودتان Save را می‌زنید.

Local .fig, .jam and .deck copies from Figma desktop, saved by an AI with desktop control, or by you pressing Save.

🔄 به‌روز ماندنStays current

فایل‌هایی که بعد از پشتیبان‌گیری در فیگما عوض شده‌اند پیدا می‌شوند و دوباره خروجی می‌گیرند، بدون اینکه چیزی پاک شود.

Files changed in Figma since the backup are found and exported again, without deleting anything.

📂 فقط آنچه لازم داریدOnly what you need

کل تیم یا فقط چند فایل با لینک. صفحه‌ها را تک‌تک انتخاب کنید؛ صفحه‌های آرشیو و جداکننده خودبه‌خود کنار می‌مانند.

A whole team or just a few files by link. Pick pages one by one; archive and divider pages are left out by default.

چطور کار می‌کندHow it works

هوش مصنوعی فقط راه‌اندازی را انجام می‌دهد. خود پشتیبان‌گیری پایتون خالص است و توکن هوش مصنوعی مصرف نمی‌کند.

An AI only does the setup. The backup itself is plain Python, so it uses no AI tokens.

  1. ۱1

    بررسیDoctor

    پایتون، اینترنت، توکن و ابزارها را بررسی می‌کند و می‌گوید چه کاری باید بکنید.

    Checks Python, network, token and tools, and lists what you need to do.

  2. ۲2

    پرسش‌هاQuestions

    یک دور سؤال: لینک تیم یا فایل‌ها، محل ذخیره، نحوهٔ اجرا و افزونه‌ها.

    One round: a team link or file links, where to save, how to run, which extras.

  3. ۳3

    برنامهPlan

    فیگما را می‌گردد و تعداد صفحه‌ها، زمان و حجم را تخمین می‌زند.

    Scans Figma and estimates screens, time and size.

  4. ۴4

    صفحه‌هاPages

    همهٔ صفحه‌ها با ✔ یا ✖؛ تا شما تأیید نکنید، اجرا شروع نمی‌شود.

    Every page with ✔ or ✖; the run waits until you confirm.

  5. ۵5

    اجراRun

    در پس‌زمینه خروجی می‌گیرد، با بستن برنامه متوقف نمی‌شود و قطعی‌ها را صبر می‌کند.

    Exports in the background, survives closing the app, waits out outages.

  6. ۶6

    پایانClose

    همه‌چیز را وارسی می‌کند، صفحهٔ پوشش را می‌سازد و آرشیوها را می‌بندد.

    Verifies everything, writes the coverage page and packs archives.

کیت را دانلود کنید و از حالت فشرده دربیاورید. بعد یکی از این دو راه:

Download the kit and unzip it. Then pick one:

🤖 با دستیار هوش مصنوعیWith an AI assistant

پوشه را در یک برنامهٔ هوش مصنوعی که می‌تواند در پوشه‌ها دستور اجرا کند باز کنید (مثل Claude Code، Cursor، Copilot یا Gemini CLI) و بنویسید:

Open the folder in an AI app that can run commands in a folder (such as Claude Code, Cursor, Copilot or Gemini CLI), and say:

«از تیم فیگمای من نسخهٔ پشتیبان بگیر.»“Back up my Figma team.”

دستیار AGENTS.md را می‌خواند، سؤال‌ها را در یک پیام می‌پرسد و بقیه را انجام می‌دهد. اگر فارسی بنویسید، فارسی جواب می‌دهد.

It reads AGENTS.md, asks a few questions in one message, and runs the rest.

⌨️ بدون هوش مصنوعیOn your own

در ترمینال، داخل همان پوشه:

In a terminal, inside the folder:

python kit.py doctor   # what's ready
python kit.py init     # a few questions
python kit.py plan     # how much, how long
python kit.py pages    # choose pages
python kit.py run      # runs in the background
python kit.py close    # check and pack

فقط پایتون ۳٫۱۰ یا جدیدتر و یک توکن فیگما با دسترسی خواندن لازم است. کیت بقیه را خودش بررسی می‌کند.

You need Python 3.10+ and a read-only Figma token. The kit checks everything else.

ایمن از ابتداSafe by design

کیت فقط کپی می‌گیرد؛ به کار شما در فیگما دست نمی‌زند.

The kit only copies; it never touches your work in Figma.

🔒در فیگما فقط می‌خواندRead-only in Figma

هیچ‌وقت چیزی را ویرایش، جابه‌جا، اشتراک‌گذاری یا حذف نمی‌کند.

It never edits, moves, shares or deletes anything there.

🔑توکن روی دیسک خودتانYour token stays local

در workstation/.env می‌ماند و هیچ‌وقت چاپ یا در لاگ نوشته نمی‌شود.

It stays in workstation/.env and is never printed or logged.

🤝با فیگما مؤدبPolite to Figma

دست‌کم ۱٫۵ ثانیه بین درخواست‌ها و رعایت کامل محدودیت‌ها.

At least 1.5 s between calls, rate limits honoured in full.

🗂️چیزی پاک نمی‌شودNothing is deleted

نسخهٔ قبلی فایل‌های به‌روزشده به temp/replaced/ می‌رود.

Old copies of refreshed files move to temp/replaced/.

پرسش‌های رایجFAQ

حتماً هوش مصنوعی لازم است؟Do I need an AI?

نه. هر قدم یک دستور python kit.py … است. هوش مصنوعی فقط کار را به گفت‌وگو تبدیل می‌کند، و اگر کنترل دسکتاپ داشته باشد، فایل‌های fig را هم برایتان ذخیره می‌کند.

No. Every step is a python kit.py … command. An AI makes it a conversation, and with desktop control it can also save the .fig copies for you.

چه پلنی از فیگما لازم است؟Which Figma plan do I need?

هر پلنی برای صفحه‌ها، گالری، نسخه‌های محلی و تحویل به برنامه‌نویس کافی است. خواندن متغیرها از REST API پلن Enterprise می‌خواهد؛ در پلن‌های دیگر، از MCP فیگما یا خروجی متغیرهای خود فیگما استفاده می‌شود.

Any plan works for screens, galleries, local copies and handoff. Reading variables through the REST API needs Enterprise; on other plans, the kit uses Figma’s MCP or Figma’s own variables export.

چقدر طول می‌کشد و چه حجمی دارد؟How long does it take, and how big is it?

دستور plan هر دو را تخمین می‌زند. به‌طور تقریبی: حدود ۱۰ صفحه در دقیقه برای PNG و SVG، و حدود ۰٫۶۵ مگابایت برای هر صفحه. نسخه‌های محلی به حدود ۴۰ فایل در روز محدودند.

plan estimates both. Roughly: about 10 screens a minute for PNG + SVG, and about 0.65 MB per screen. Local copies are limited to about 40 a day.

می‌توانم فقط چند فایل را پشتیبان بگیرم؟Can I back up only some files?

بله. در سؤال‌ها به‌جای لینک تیم، لینک فایل‌ها را بدهید. صفحه‌های هر فایل را هم می‌توانید جدا انتخاب کنید.

Yes. In the interview, paste file links instead of a team link. You can also choose pages per file.

اگر برنامه یا لپ‌تاپ را ببندم چه می‌شود؟Can I close the app or my laptop during the run?

بستن برنامه مشکلی ندارد و اجرا در پس‌زمینه ادامه پیدا می‌کند. اگر کامپیوتر خوابید یا ری‌استارت شد، python kit.py resume را بزنید.

Closing the app is fine: the run continues in the background. If the computer sleeps or restarts, run python kit.py resume.

چطور یک فایل را به فیگما برگردانم؟How do I restore a file into Figma?

فایل fig را داخل فیگما بکشید، یا از منوی Import فیگما استفاده کنید.

Drag its .fig into Figma, or use Figma → Import.
