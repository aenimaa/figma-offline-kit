## 🚀 شروع در یک دقیقه

**پایتون ۳٫۱۰ یا جدیدتر باید نصب باشد** (رایگان است؛ کیت با آن کار می‌کند و چیز دیگری نصب نمی‌کند) و یک **[توکن فیگما](docs/figma-token.md)** با دسترسی خواندن. اگر پایتون نصب نباشد، فایل Start پیشنهاد می‌دهد نصبش کند و اول از شما می‌پرسد.

**🖱️ با دوبار کلیک، بدون هوش مصنوعی:**<br>
۱. نسخهٔ **[ویندوز](https://aenimaa.github.io/figma-offline-kit/downloads/figma-offline-kit-windows.zip)** یا **[مک](https://aenimaa.github.io/figma-offline-kit/downloads/figma-offline-kit-macos.zip)** را دانلود کنید و از حالت فشرده دربیاورید.<br>
۲. در ویندوز روی **`Start.bat`** و در مک روی **`Start.command`** دوبار کلیک کنید.<br>
اول زبان را می‌پرسد (فارسی / English)، بعد قدم‌به‌قدم همراهتان است، پیشرفت پشتیبان‌گیری را زنده نشان می‌دهد و از همان جایی که مانده‌اید ادامه می‌دهد.

**🤖 با دستیار هوش مصنوعی:** این مخزن را بگیرید ([ZIP](https://github.com/aenimaa/figma-offline-kit/archive/refs/heads/main.zip) یا `git clone`) و پوشه را در برنامه‌ای باز کنید که **می‌تواند روی کامپیوتر شما دستور اجرا کند**: Claude Code یا Claude دسکتاپ، Cursor، حالت agent در Copilot داخل VS Code، Gemini CLI یا Codex. بنویسید: **«از تیم فیگمای من نسخهٔ پشتیبان بگیر.»** دستیار [`AGENTS.md`](AGENTS.md) را می‌خواند، سؤال‌ها را در یک پیام می‌پرسد و بقیه را انجام می‌دهد. اگر فارسی بنویسید، فارسی جواب می‌دهد.

**⌨️ در ترمینال:** دستور `python kit.py start --lang fa` همان راهنمای قدم‌به‌قدم است، در این مخزن یا در پوشهٔ `app` نسخهٔ دانلودی. یا قدم‌ها را جدا بزنید:

</div>

```
python kit.py doctor      # چه چیزی آماده است
python kit.py init        # چند سؤال
python kit.py plan        # چه مقدار و در چه مدت
python kit.py pages       # انتخاب صفحه‌ها
python kit.py run         # در پس‌زمینه اجرا می‌شود
python kit.py close       # وارسی و بستن آرشیو
```

<div dir="rtl">

**🔑 جای توکن:** فایل `workstation/.env` داخل پوشهٔ پشتیبان، بعد از `FIGMA_TOKEN=`. با پوشهٔ پیش‌فرض، در ویندوز و مک:

</div>

```
C:\Users\<you>\figma-backup\workstation\.env
~/figma-backup/workstation/.env        (macOS)
```

<div dir="rtl">

راهنمای قدم‌به‌قدم مسیر دقیق را نشان می‌دهد، می‌گذارد توکن را همان‌جا بچسبانید (دیده نمی‌شود) یا فایلی را در Notepad یا TextEdit برایتان باز می‌کند، و با فیگما امتحانش می‌کند. در نسخهٔ دانلودی می‌توانید توکن را در **`Figma token.txt`** کنار Start هم بچسبانید: Start آن را به `.env` می‌برد و فایل txt را خالی می‌کند.

**📝 همه‌چیز نوشته می‌شود:** فایل `REPORT.md` بالای پوشهٔ پشتیبان، تنظیمات شما را به‌صورت تصمیم‌های ساده، نتیجهٔ هر قدم و گزارشی تاریخ‌دار از همهٔ قدم‌ها و تصمیم‌ها نگه می‌دارد.

</div>

<details>
<summary><b>در فایل دانلودی چه هست</b></summary>

```
figma-offline-kit-windows/          (یا -macos)
├─ Start.bat                        روی این دوبار کلیک کنید (در مک Start.command)
├─ Read me first.html               سه قدم، به انگلیسی و فارسی
├─ Figma token.txt                  توکن را اینجا بچسبانید (Start آن را به جای امن می‌برد)
├─ app/                             خود کیت: kit.py، kit/، templates/، LICENSE
└─ guides/                          راهنماها: توکن، نسخهٔ محلی، توکن‌های طراحی، تحویل، پرسش‌ها، رفع اشکال
```

<div dir="rtl">
فایل‌های دانلودی برای کسانی است که بدون هوش مصنوعی کار می‌کنند و `AGENTS.md` و فایل‌های هوش مصنوعی را ندارند. **کاربران هوش مصنوعی از همین مخزن استفاده کنند**، که همه‌چیز (و تست‌ها) را دارد.
</div>
</details>

<div dir="rtl">

- **هوش مصنوعیِ فقط‌چت** (ChatGPT یا Claude در تب مرورگر) نمی‌تواند کیت را اجرا کند، چون روی کامپیوتر شما دستور اجرا نمی‌کند. از راه دوبار کلیک استفاده کنید.
- **مک بار اول `Start.command` را باز نمی‌کند** چون از اینترنت دانلود شده: System Settings ← Privacy & Security ← *Open Anyway*، یا در Terminal بزنید `bash Start.command`.
- **ویندوز برای فایل‌های اینترنتی هشدار می‌دهد.** برای اینکه هشدار نیاید، قبل از باز کردن ZIP روی آن راست‌کلیک کنید ← *Properties* ← تیک *Unblock* ← *OK*. وگرنه در «Open File – Security Warning … Are you sure you want to run this software?» دکمهٔ *Run* را بزنید، یا در «Windows protected your PC» اول *More info* و بعد *Run anyway*.
- **لینوکس:** در این مخزن `bash start.command`.
- **فارسی در ویندوز:** ترمینال ویندوز فارسی را برعکس و جدا‌جدا نشان می‌دهد، برای همین پنجرهٔ Start در ویندوز انگلیسی است. اگر فارسی را انتخاب کنید، گزارش (`REPORT.md`) و صفحه‌ها فارسی می‌شوند. در مک خود پنجره هم فارسی است.

## 🧭 کی به کارتان می‌آید

- **فیگما یا اینترنت قطع است** و همین امروز صفحه‌ها را لازم دارید.
- **دسترسی‌تان قطع می‌شود:** از یک تیم یا مشتری جدا می‌شوید، پلن پایین می‌آید یا حساب مسدود می‌شود.
- **برنامه‌نویس مشخصات را لازم دارد** و صندلی فیگما ندارد.
- **سندی از یک تاریخ:** آنچه در زمان تحویل یا انتشار وجود داشت، با صفحهٔ پوشش برای اثباتش.

### 💾 و خود فایل‌ها

نسخه‌های محلی **`.fig`، `.jam` و `.deck`** از فیگمای دسکتاپ؛ یا هوش مصنوعیِ دارای کنترل دسکتاپ آن‌ها را ذخیره می‌کند، یا خودتان دکمهٔ Save را می‌زنید. با فاصلهٔ کافی، تا بررسی ضدربات فیگما فعال نشود. [بیشتر](docs/local-copies.md)

## ⚙️ چطور کار می‌کند

| | قدم | چه اتفاقی می‌افتد |
|---|---|---|
| ۱ | **بررسی** | پایتون، اینترنت، توکن و ابزارها را بررسی می‌کند و می‌گوید چه چیزی آماده است و چه کاری باید بکنید |
| ۲ | **پرسش‌ها** | یک دور سؤال: لینک تیم یا فایل‌ها، محل ذخیره، نحوهٔ اجرا، صفحه‌ها و افزونه‌ها |
| ۳ | **برنامه** | فیگما را می‌گردد و تعداد صفحه‌ها، زمان و حجم را تخمین می‌زند |
| ۴ | **صفحه‌ها** | همهٔ صفحه‌ها با ✔ یا ✖؛ صفحه‌های آرشیو و جداکننده کنار می‌مانند، مگر اینکه خودتان بخواهید |
| ۵ | **اجرا** | در پس‌زمینه خروجی می‌گیرد، با بستن برنامه متوقف نمی‌شود، قطعی‌ها را صبر می‌کند و ادامه می‌دهد |
| ۶ | **پایان** | همه‌چیز را وارسی می‌کند، فایل‌های عوض‌شده را نشان می‌دهد، صفحهٔ پوشش را می‌سازد و آرشیوها را می‌بندد |

## 🔒 ایمن از ابتدا

- **در فیگما فقط می‌خواند.** هیچ‌وقت چیزی را در فیگما ویرایش، جابه‌جا، اشتراک‌گذاری یا حذف نمی‌کند.
- **توکن شما روی دیسک خودتان می‌ماند**، در `workstation/.env`، و هیچ‌وقت چاپ یا در گزارش و لاگ نوشته نمی‌شود.
- **با فیگما مؤدب است:** دست‌کم ۱٫۵ ثانیه بین درخواست‌ها، رعایت کامل محدودیت‌ها، و حدود ۴۰ نسخهٔ محلی در روز.
- **چیزی پاک نمی‌شود.** نسخهٔ قبلی فایل‌هایی که دوباره خروجی می‌گیرند به `temp/replaced/` منتقل می‌شود.
