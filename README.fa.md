## 🚀 شروع در یک دقیقه

**۱ · کیت را بگیرید:** [فایل ZIP را دانلود کنید](https://github.com/aenimaa/figma-offline-kit/archive/refs/heads/main.zip) و از حالت فشرده دربیاورید (یا این مخزن را `git clone` کنید).

**۲ · یکی از این راه‌ها:**

**🖱️ با دوبار کلیک:** در ویندوز **`start.bat`** و در مک **`start.command`**. قدم‌به‌قدم همراهتان است، از همان جایی که مانده‌اید ادامه می‌دهد و چیزی نصب نمی‌کند.

**🤖 با دستیار هوش مصنوعی:** پوشه را در برنامه‌ای باز کنید که **می‌تواند روی کامپیوتر شما دستور اجرا کند**: Claude Code یا Claude دسکتاپ، Cursor، حالت agent در Copilot داخل VS Code، Gemini CLI یا Codex. بنویسید: **«از تیم فیگمای من نسخهٔ پشتیبان بگیر.»** دستیار [`AGENTS.md`](AGENTS.md) را می‌خواند، سؤال‌ها را در یک پیام می‌پرسد و بقیه را انجام می‌دهد. اگر فارسی بنویسید، فارسی جواب می‌دهد.

**⌨️ در ترمینال:** دستور `python kit.py start` همان راهنمای قدم‌به‌قدم است. یا قدم‌ها را جدا بزنید:

</div>

```
python kit.py doctor      # چه چیزی آماده است
python kit.py init        # چند سؤال
python kit.py plan        # چه مقدار و در چه مدت
python kit.py pages       # انتخاب صفحه‌ها
python kit.py run         # در پس‌زمینه اجرا می‌شود
python kit.py close       # وارسی و بستن آرشیو
```

<div dir="rtl">

فقط **پایتون ۳٫۱۰ یا جدیدتر** (اگر نصب نباشد، فایل‌های start لینکش را باز می‌کنند) و یک **[توکن فیگما](docs/figma-token.md)** با دسترسی خواندن لازم است. کیت بقیه را خودش بررسی می‌کند و می‌گوید چه چیزی کم است.

- **هوش مصنوعیِ فقط‌چت** (ChatGPT یا Claude در تب مرورگر) نمی‌تواند کیت را اجرا کند، چون روی کامپیوتر شما دستور اجرا نمی‌کند. از راه دوبار کلیک استفاده کنید.
- **مک بار اول `start.command` را باز نمی‌کند** چون از اینترنت دانلود شده: System Settings ← Privacy & Security ← *Open Anyway*، یا در Terminal بزنید `bash start.command`.
- **لینوکس:** `bash start.command`.

## 🧭 کی به کارتان می‌آید

- **فیگما یا اینترنت قطع است** و همین امروز صفحه‌ها را لازم دارید.
- **دسترسی‌تان قطع می‌شود:** از یک تیم یا مشتری جدا می‌شوید، پلن پایین می‌آید یا حساب مسدود می‌شود.
- **برنامه‌نویس مشخصات را لازم دارد** و صندلی فیگما ندارد.
- **سندی از یک تاریخ:** آنچه در زمان تحویل یا انتشار وجود داشت، با صفحهٔ پوشش برای اثباتش.

## 📦 چه چیزی تحویل می‌گیرید

### 🗺️ گالری آفلاین برای هر فایل

### 💾 و خود فایل‌ها

نسخه‌های محلی **`.fig`، `.jam` و `.deck`** از فیگمای دسکتاپ؛ یا هوش مصنوعیِ دارای کنترل دسکتاپ آن‌ها را ذخیره می‌کند، یا خودتان دکمهٔ Save را می‌زنید. با فاصلهٔ کافی، تا بررسی ضدربات فیگما فعال نشود. [بیشتر](docs/local-copies.md)

## 💳 چه پلنی از فیگما لازم است

| چه چیزی | پلن | توضیح |
|---|---|---|
| صفحه‌ها (PNG و SVG)، گالری آفلاین، صفحهٔ پوشش، آرشیوها | هر پلنی | توکنی با دسترسی خواندن |
| نسخه‌های محلی fig، jam و deck | هر پلنی | فیگمای دسکتاپ |
| توکن‌های طراحی از REST API | Enterprise | پلن‌های دیگر: MCP فیگما یا خروجی متغیرهای خود فیگما ([توکن‌ها](docs/tokens.md)) |
| تحویل به برنامه‌نویس | هر پلنی | قدم کد، سرور MCP فیگمای دسکتاپ را لازم دارد ([تحویل](docs/handoff.md)) |

## ⚙️ چطور کار می‌کند

| | قدم | چه اتفاقی می‌افتد |
|---|---|---|
| ۱ | **بررسی** | پایتون، اینترنت، توکن و ابزارها را بررسی می‌کند و می‌گوید چه چیزی آماده است و چه کاری باید بکنید |
| ۲ | **پرسش‌ها** | یک دور سؤال: لینک تیم یا فایل‌ها، محل ذخیره، نحوهٔ اجرا، صفحه‌ها و افزونه‌ها |
| ۳ | **برنامه** | فیگما را می‌گردد و تعداد صفحه‌ها، زمان و حجم را تخمین می‌زند |
| ۴ | **صفحه‌ها** | همهٔ صفحه‌ها با ✔ یا ✖؛ صفحه‌های آرشیو و جداکننده کنار می‌مانند، مگر اینکه خودتان بخواهید |
| ۵ | **اجرا** | در پس‌زمینه خروجی می‌گیرد، با بستن برنامه متوقف نمی‌شود، قطعی‌ها را صبر می‌کند و ادامه می‌دهد |
| ۶ | **پایان** | همه‌چیز را وارسی می‌کند، فایل‌های عوض‌شده را نشان می‌دهد، صفحهٔ پوشش را می‌سازد و آرشیوها را می‌بندد |

## 🔒 ایمن از ابتدا

- **در فیگما فقط می‌خواند.** هیچ‌وقت چیزی را در فیگما ویرایش، جابه‌جا، اشتراک‌گذاری یا حذف نمی‌کند.
- **توکن شما روی دیسک خودتان می‌ماند**، در `workstation/.env`، و هیچ‌وقت چاپ یا در گزارش و لاگ نوشته نمی‌شود.
- **با فیگما مؤدب است:** دست‌کم ۱٫۵ ثانیه بین درخواست‌ها، رعایت کامل محدودیت‌ها، و حدود ۴۰ نسخهٔ محلی در روز.
- **چیزی پاک نمی‌شود.** نسخهٔ قبلی فایل‌هایی که دوباره خروجی می‌گیرند به `temp/replaced/` منتقل می‌شود.
