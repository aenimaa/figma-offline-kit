# figma-offline-kit

**وقتی فیگما یا اینترنت قطع است، کارتان متوقف نشود.** این کیت از تیم فیگمای شما، یا فقط فایل‌هایی که انتخاب می‌کنید، روی دیسک خودتان نسخهٔ پشتیبان می‌سازد: همهٔ صفحه‌ها به‌صورت تصویر، یک گالری آفلاین که مثل بوم فیگما می‌شود در آن گشت، نسخه‌های محلی `.fig`، توکن‌های طراحی و بستهٔ تحویل برای برنامه‌نویس‌ها.

با هر دستیار هوش مصنوعی (Claude، Gemini، Copilot، Cursor، ChatGPT و…) یا بدون آن کار می‌کند. فقط پایتون ۳٫۱۰ یا جدیدتر لازم است و چیزی نصب نمی‌شود. روی ویندوز، مک و لینوکس.

## چه چیزی تحویل می‌گیرید

| | |
|---|---|
| **صفحه‌ها** | همهٔ فریم‌های صفحه‌هایی که انتخاب می‌کنید، به‌صورت PNG و SVG (و PDF هر جا فیگما SVG نسازد)، در پوشه‌های پروژه ← فایل ← صفحه ← سکشن |
| **گالری آفلاین** | برای هر فایل یک `index.html`: نمای شبکه‌ای، نقشه‌ای که جای هر فریم را روی بوم نشان می‌دهد، درخت صفحه‌ها، فیلترها، نمایشگر تمام‌صفحه و لینک برگشت به فیگما |
| **نسخهٔ محلی** | فایل‌های `.fig`، `.jam`، `.deck` و `.make` که فیگمای دسکتاپ ذخیره می‌کند، تا خود فایل را دوباره وارد فیگما کنید |
| **توکن‌های طراحی** | متغیرهای شما به‌صورت `tokens.css` و `_tokens.scss`، گزارش اینکه هر صفحه از کدام توکن‌ها و استایل‌ها استفاده می‌کند، و SVGهایی که رنگ‌هایشان به توکن‌ها اشاره می‌کند |
| **تحویل به برنامه‌نویس** | برای صفحه‌هایی که برنامه‌نویس لازم دارد: یک صفحه برای هر فریم با طراحی، کد، توکن‌ها و آناتومی کامپوننت |
| **پوشش و آرشیو** | صفحهٔ `COVERAGE.html` که نشان می‌دهد پشتیبان چه دارد و از آن به بعد چه چیزی در فیگما عوض شده، به‌اضافهٔ یک آرشیو آزموده برای هر پروژه |

گالری را با داده‌های ساختگی ببینید: [`examples/demo/Mobile App/Onboarding/index.html`](examples/demo/Mobile%20App/Onboarding/index.html) و [`examples/demo/COVERAGE.html`](examples/demo/COVERAGE.html).

## چه چیزهایی لازم است

- **پایتون ۳٫۱۰ یا جدیدتر** ([python.org](https://www.python.org/downloads/)).
- **توکن دسترسی شخصی فیگما** فقط با دسترسی خواندن. [راهنمای ساخت توکن](docs/figma-token.md) (انگلیسی).
- اختیاری: **فیگمای دسکتاپ** برای نسخه‌های محلی و کدِ بستهٔ تحویل؛ **7-Zip** یا **WinRAR** برای آرشیو کوچک‌تر؛ هوش مصنوعی با **کنترل دسکتاپ** تا نسخه‌های محلی را خودش ذخیره کند؛ **سرور MCP فیگما** در هوش مصنوعی‌تان برای خواندن متغیرها بدون پلن Enterprise.

کیت همهٔ این‌ها را خودش بررسی می‌کند و می‌گوید چه چیزی کم است.

## شروع با هوش مصنوعی

این پوشه را در برنامهٔ هوش مصنوعی‌تان باز کنید و بنویسید: *«از تیم فیگمای من نسخهٔ پشتیبان بگیر.»*

هوش مصنوعی فایل [`AGENTS.md`](AGENTS.md) را می‌خواند و قدم‌به‌قدم همراهتان می‌آید: بررسی آمادگی، چند سؤال در یک پیام، برنامهٔ کار، انتخاب صفحه‌ها و بعد خودِ پشتیبان‌گیری. شما فقط جواب می‌دهید و هر جا فیگما دست آدم لازم دارد، دکمهٔ Save را می‌زنید. اگر به فارسی بنویسید، با شما فارسی حرف می‌زند؛ در پرسش‌ها هم اگر زبان را فارسی انتخاب کنید، هوش مصنوعی همیشه فارسی جواب می‌دهد. (فایل‌های گزارش خودِ کیت فعلاً انگلیسی‌اند.)

## شروع بدون هوش مصنوعی

</div>

```
python kit.py doctor      # چه چیزی آماده است و شما چه کاری باید بکنید
python kit.py init        # چند سؤال؛ پوشهٔ کار ساخته می‌شود
python kit.py plan        # چه چیزی، در چه مدت و با چه حجمی پشتیبان می‌شود
python kit.py pages       # انتخاب صفحه‌ها، بعد: python kit.py pages --confirm
python kit.py run         # در پس‌زمینه اجرا می‌شود و با بستن پنجره متوقف نمی‌شود
python kit.py status      # پیشرفت کار (stop و resume برای توقف و ادامه)
python kit.py close       # بررسی همه‌چیز، صفحهٔ پوشش، آرشیوها
```

## چطور کار می‌کند

۱. **بررسی (doctor):** پایتون، اینترنت، توکن، فیگمای دسکتاپ و ابزارهای اختیاری را بررسی می‌کند و دو فهرست می‌دهد: *کارهایی که از من برمی‌آید* و *کارهایی که شما باید بکنید*.

۲. **پرسش‌ها:** یک دور سؤال. از چه چیزی پشتیبان بگیرد (لینک تیم یا لینک فایل‌ها)، کجا ذخیره کند، چطور اجرا شود (یک‌جا، پروژه‌به‌پروژه یا فایل‌به‌فایل)، کدام صفحه‌ها، چه قالب‌ها و چه افزونه‌هایی.

۳. **برنامه (plan):** فیگما را می‌گردد و تعداد صفحه‌ها، زمان و حجم را تخمین می‌زند.

۴. **صفحه‌ها (pages):** همهٔ صفحه‌های هر فایل را با ✔ یا ✖ می‌بینید و انتخاب می‌کنید. صفحه‌های آرشیو و صفحه‌های جداکننده به‌طور پیش‌فرض کنار گذاشته می‌شوند. تا تأیید نکنید، اجرا شروع نمی‌شود.

۵. **اجرا (run):** در پس‌زمینه خروجی می‌گیرد و با بستن برنامه یا هوش مصنوعی متوقف نمی‌شود. اگر یک فایل خطا بدهد، بقیه ادامه پیدا می‌کنند؛ اگر اینترنت قطع شود، صبر می‌کند؛ و `resume` از همان جایی که مانده ادامه می‌دهد.

۶. **پایان (close):** همهٔ صفحه‌ها و نسخه‌ها را وارسی می‌کند، فایل‌هایی را که بعد از پشتیبان‌گیری در فیگما عوض شده‌اند پیدا می‌کند (`refresh` دوباره خروجی‌شان را می‌گیرد)، صفحهٔ پوشش را می‌سازد و آرشیوهای آزموده را می‌بندد.

## پوشهٔ کار

</div>

```
<workspace>/
├─ backup/            خروجی اصلی
│  ├─ COVERAGE.html   پشتیبان چه چیزهایی دارد
│  ├─ <project>.zip   برای هر پروژه یک آرشیو آزموده
│  └─ <project>/<file>/
│     ├─ index.html   گالری آفلاین
│     ├─ <file>.fig   نسخهٔ محلی (برای برگرداندن: Figma ← Import)
│     ├─ screens/png · svg · pdf · svg-tokens/<page>/[<section>/]NNN <frame> [<id>].<ext>
│     └─ variables/   tokens.css · _tokens.scss · variables.figma.json
├─ handoff/<name>/    بسته‌های تحویل به برنامه‌نویس
├─ temp/              فایل‌های موقت، پاک کردنشان بی‌خطر است
└─ workstation/       REPORT.md (گزارش پیشرفت) · تنظیمات · لاگ‌ها · .env (توکن شما)
```

<div dir="rtl">

گالری‌ها مستقیم از روی دیسک باز می‌شوند. اگر مرورگری صفحه‌های `file://` را باز نکرد، پوشه را این‌طور سرو کنید: `python -m http.server --directory "<workspace>/backup"`.

## ایمن از ابتدا

- **در فیگما فقط می‌خواند.** کیت هیچ‌وقت چیزی را در فیگما ویرایش، جابه‌جا، اشتراک‌گذاری یا حذف نمی‌کند.
- **توکن شما روی دیسک خودتان می‌ماند**، در `workstation/.env`، و هیچ‌وقت چاپ یا در گزارش و لاگ نوشته نمی‌شود.
- **با سرورهای فیگما مؤدب است:** دست‌کم ۱٫۵ ثانیه بین درخواست‌ها، رعایت کامل محدودیت‌های فیگما، و ذخیرهٔ حدود ۴۰ نسخهٔ محلی در روز تا بررسی ضدربات فیگما فعال نشود.
- **چیزی پاک نمی‌شود.** فایل‌هایی که دوباره خروجی می‌گیرند، نسخهٔ قبلی‌شان به `temp/replaced/` منتقل می‌شود.
